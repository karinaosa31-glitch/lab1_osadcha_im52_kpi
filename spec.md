# Специфікація моделі даних (spec.md)

## 1. Сутності та атрибути

### book (Книга)
Описує бібліографічні дані видання в каталозі бібліотеки.
- `book_id` (`SERIAL`, PK) — унікальний ідентифікатор книги.
- `title` (`TEXT`) — назва книги.
- `genre` (`TEXT`) — жанр або категорія видання.
- `ISBN` (`TEXT`, UK) — міжнародний стандартний номер книги.
- `year_of_publication` (`INT`) — рік публікації видання (ціле число більше 0 і не більше поточного року).
- `pages_count` (`INT`) — кількість сторінок (ціле число більше 0).
- `language` (`TEXT`) — мова видання (за замовчуванням Ukrainian).

### author (Автор)
Зберігає інформацію про авторів книг.
- `author_id` (`SERIAL`, PK) — унікальний ідентифікатор автора.
- `author_name` (`TEXT`) — повне ім'я або псевдонім автора.
- `country` (`TEXT`) — країна походження автора.

### copy (Фізичний примірник)
Представляє окрему фізичну копію книги у фонді бібліотеки.
- `copy_id` (`SERIAL`, PK) — унікальний ідентифікатор примірника.
- `book_id` (`INT`, FK -> `book.book_id`) — ID книги в каталозі.
- `inventory_number` (`TEXT`, UK) — унікальний бібліотечний інвентарний номер.
- `shelf_location` (`TEXT`) — місце зберігання примірника (стелаж, полиця).
- `book_condition` (`TEXT`) — опис фізичного стану книги.
- `status` (`copy_status`) — статус доступності примірника (`available`, `borrowed`, `damaged`, `lost`).

### reader (Читач)
Позначає зареєстрованого користувача бібліотеки, який може брати книги.
- `reader_id` (`SERIAL`, PK) — унікальний ідентифікатор читача.
- `reader_name` (`TEXT`) — прізвище та ім'я читача (обов'язково).
- `phone_number` (`TEXT`) — контактний номер телефону (необов'язково).
- `email` (`TEXT`, UK) — електронна пошта читача (обов'язково).
- `registration_date` (`DATE`) — дата реєстрації в бібліотеці.
- `status` (`reader_status`) — статус облікового запису читача (`active`, `blocked`, `inactive`).

### librarian (Бібліотекар)
Позначає працівника бібліотеки, який обслуговує читачів та оформлює видачу книг.
- `librarian_id` (`SERIAL`, PK) — унікальний ідентифікатор бібліотекаря.
- `librarian_name` (`TEXT`) — прізвище та ім'я бібліотекаря.
- `email` (`TEXT`, UK) — робоча електронна пошта.

### borrowing (Видача книги)
Описує факт видачі конкретного фізичного примірника читачеві та його повернення.
- `borrowing_id` (`SERIAL`, PK) — унікальний ідентифікатор операції видачі.
- `copy_id` (`INT`, FK -> `copy.copy_id`) — ID фізичного примірника книги.
- `reader_id` (`INT`, FK -> `reader.reader_id`) — ID читача, який взяв книгу.
- `librarian_id` (`INT`, FK -> `librarian.librarian_id`) — ID бібліотекаря, який оформив видачу.
- `borrow_date` (`DATE`) — дата видачі книги.
- `due_date` (`DATE`) — планова дата повернення книги (не менша за `borrow_date`).
- `return_date` (`DATE`) — фактична дата повернення (`NULL`, якщо книга ще не повернута).
- `fine_status` (`fine_status`) — статус штрафу за прострочення (`not overdue`, `overdue`, `paid`)( початково `not overdue`).
- `fine_amount` (`NUMERIC(8,2)`) — сума нарахованого штрафу (невід'ємне число, початково 0.00).

## 2. Зв'язки між сутностями

- `book` ↔ `author` (M:N): Одна книга може бути написана кількома авторами, а один автор — створити багато книг.
- `book` ↔ `copy` (1:N): Одне видання в каталозі може мати багато фізичних примірників.
- `copy` ↔ `borrowing` (1:N): Один фізичний примірник може видаватися в межах багатьох операцій видачі в різний час.
- `reader` ↔ `borrowing` (1:N): Один читач може оформити багато видач книг.
- `librarian` ↔ `borrowing` (1:N): Один бібліотекар може оформити багато видач книг.

## 3. Критерії прийняття (Acceptance Criteria)

- Модель даних повинна бути нормалізована (3NF).
- Усі зв'язки між сутностями предметної області мають бути явними, без додавання технічних сполучних таблиць без власних атрибутів.
- Кожна сутність повинна мати типізований Primary Key (`SERIAL`).
- Зовнішні ключі (Foreign Keys) мають чітко посилатися на відповідні первинні ключі батьківських сутностей та збігатися за типом даних (`INT`).
- Домени значень (статуси, дати, суми штрафів, унікальні коди ISBN та інвентарні номери) повинні бути захищені відповідними обмеженнями цілісності.

## 4. Актори та їхні цілі

1. Відвідувач (Guest) — *Людина (Базовий/Узагальнений актор)*
- Опис: Особа яка може бути не зареєстрована в бібліотеці, яка потім може стати читачем.
- Цілі: Знайти книгу за автором чи жанром і дізнатися, чи є вільні примірники.

2. Читач (Reader) — *Людина (Спеціалізований актор / Нащадок Guest)*
- Опис: Особа з читацьким квитком, яка шукає, бере, повертає книги в бібліотеці.
- Цілі: Те що й у відвідувача і додатково повернути/взяти книгу, контролювати свої видачі, терміни повернення та штрафи.

3. Бібліотекар (Librarian) — *Людина (Первинний актор)*
- Опис: Особа, яка працює в бібліотеці та надає послуги читачам та відвідувачам.
- Цілі: Видавати/приймати книги, реєструвати читачів, слідкувати за історією видач та прострочень.
